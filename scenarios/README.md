## How to practise

1. Read the scenario description and identify the primary domains.
2. Answer each question before opening the explanation.
3. Separate the direct architectural requirement from the process of eliminating distractors.
4. Follow the linked task statements and trace the answer back to a rule or trade-off.
5. Review the implementation section only after attempting the full scenario.
