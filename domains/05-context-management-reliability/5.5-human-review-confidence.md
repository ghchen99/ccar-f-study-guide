# 5.5 Design human review workflows and confidence calibration

## Knowledge of

- The risk that aggregate accuracy metrics (e.g., 97% overall) may mask poor performance on specific document types or fields.
- Stratified random sampling for measuring error rates in high-confidence extractions and detecting novel error patterns.
- Field-level confidence scores calibrated using labeled validation sets for routing review attention.
- The importance of validating accuracy by document type and field segment before automating high-confidence extractions.

## Skills in

- Implementing stratified random sampling of high-confidence extractions for ongoing error rate measurement and novel pattern detection.
- Analyzing accuracy by document type and field to verify consistent performance across all segments before reducing human review.
- Having models output field-level confidence scores, then calibrating review thresholds using labeled validation sets.
- Routing extractions with low model confidence or ambiguous/contradictory source documents to human review, prioritizing limited reviewer capacity.

### Aggregate accuracy hides segment failures

```python
import pandas as pd

df = pd.read_csv("labelled_validation.csv")     # columns: doc_type, field, correct (bool), confidence

print("overall", df.correct.mean())                                   # 0.97 looks fine
print(df.groupby("doc_type").correct.mean())                          # but handwritten_receipts: 0.71
print(df.groupby(["doc_type", "field"]).correct.agg(["mean", "count"]).sort_values("mean").head(10))
```

Validate accuracy by document type and by field before automating anything.

### Calibrate thresholds on a labelled validation set

```python
def precision_at(df, field: str, threshold: float) -> float:
    kept = df[(df.field == field) & (df.confidence >= threshold)]
    return kept.correct.mean()


# smallest threshold where auto-accepted fields meet the accuracy target
def pick_threshold(df, field: str, target: float = 0.98) -> float:
    for t in [i / 100 for i in range(50, 100)]:
        if precision_at(df, field, t) >= target:
            return t
    return 1.01     # never auto-accept this field
```

Calibrate per field; model self-reported confidence is only meaningful once checked against labels.

### Route to human review

```python
def route(extraction: dict, thresholds: dict[str, float], source_flags: dict) -> str:
    if source_flags.get("contradictory") or source_flags.get("ambiguous"):
        return "human_review"
    for field, item in extraction.items():
        if item["confidence"] < thresholds[field]:
            return "human_review"
    return "auto_accept"
```

### Stratified random sampling of high-confidence output

Keep measuring after automation: sample auto-accepted extractions per document type and field, and review them.

```python
import random

def sample_for_audit(auto_accepted: list[dict], per_stratum: int = 20) -> list[dict]:
    strata: dict[tuple, list[dict]] = {}
    for rec in auto_accepted:
        strata.setdefault((rec["doc_type"], rec["field"]), []).append(rec)
    return [r for recs in strata.values() for r in random.sample(recs, min(per_stratum, len(recs)))]
```

This estimates the error rate of high-confidence output and surfaces new error patterns, and lets you prioritise limited reviewer time on the low-confidence and contradictory cases.
