# 5.5 Design human review workflows and confidence calibration

> [!NOTE]
> **At a glance**
>
> - **Aggregate trap:** 97% overall can hide poor accuracy on one document type or field; validate by segment first.
> - **Calibration:** field-level confidence is only meaningful once checked against a labelled validation set.
> - **Routing:** send low-confidence, ambiguous or contradictory items to reviewers.
> - **Ongoing audit:** stratified random sampling of auto-accepted output measures error rates and surfaces novel patterns.

## Example

### Aggregate accuracy hides segment failures

```python
import pandas as pd

df = pd.read_csv("labelled_validation.csv")     # columns: doc_type, field, correct (bool), confidence

print("overall", df.correct.mean())                                   # 0.97 looks fine
print(df.groupby("doc_type").correct.mean())                          # but handwritten_receipts: 0.71
# Count matters: a 100% mean on a handful of rows is not evidence.
print(df.groupby(["doc_type", "field"]).correct.agg(["mean", "count"]).sort_values("mean").head(10))
```

Validate accuracy by document type and by field before automating anything.

### Field-level confidence in the extraction schema

```json
{
  "vendor": {"value": "Acme Corp", "confidence": 0.97},
  "total": {"value": 500.00, "confidence": 0.62},
  "due_date": {"value": null, "confidence": 0.0}
}
```

### Calibrate thresholds on a labelled validation set

```python
def precision_at(df, field: str, threshold: float) -> float:
    # Measured against human labels: this is what turns a raw confidence number into a real accuracy estimate.
    kept = df[(df.field == field) & (df.confidence >= threshold)]
    return kept.correct.mean()


# smallest threshold where auto-accepted fields meet the accuracy target
def pick_threshold(df, field: str, target: float = 0.98) -> float:
    for t in [i / 100 for i in range(50, 100)]:
        if precision_at(df, field, t) >= target:
            return t
    return 1.01     # never auto-accept this field
```

Calibrate per field; model self-reported confidence is only meaningful once checked against labels.

### Route to human review

```python
def route(extraction: dict, thresholds: dict[str, float], source_flags: dict) -> str:
    # Source problems override confidence: a model can be confident about a value the document itself contradicts.
    if source_flags.get("contradictory") or source_flags.get("ambiguous"):
        return "human_review"
    for field, item in extraction.items():
        if item["confidence"] < thresholds[field]:
            return "human_review"
    return "auto_accept"
```

### Stratified random sampling of high-confidence output

Keep measuring after automation: sample auto-accepted extractions per document type and field, and review them.

```python
import random

def sample_for_audit(auto_accepted: list[dict], per_stratum: int = 20) -> list[dict]:
    # Stratify by type and field so rare segments are sampled, which a single uniform sample would underrepresent.
    strata: dict[tuple, list[dict]] = {}
    for rec in auto_accepted:
        strata.setdefault((rec["doc_type"], rec["field"]), []).append(rec)
    return [r for recs in strata.values() for r in random.sample(recs, min(per_stratum, len(recs)))]
```

This estimates the error rate of high-confidence output, surfaces new error patterns and lets limited reviewer time go to low-confidence and contradictory cases.

## How it works

> [!IMPORTANT]
> **Automation is earned segment by segment, through measurement rather than trust.** Treat confidence as a hypothesis to calibrate, judge accuracy per document type and field, and keep sampling after automation starts.

1. **Break down the aggregate.** 97% overall is compatible with 71% on a small handwritten-receipts segment; group by type, then type and field. The `count` column stops a perfect mean on a handful of rows counting as proof.
2. **Score per field.** A `value` and `confidence` per field targets review at `total` (0.62), not a whole document. A null `due_date` at 0.0 is a legitimate "not present" signal.
3. **Calibrate thresholds.** Per field, find the lowest cut-off where auto-accepted values meet the target on labelled data; 1.01 means never auto-accept. Raw confidence is not assumed to equal probability of being correct.
4. **Let sources override confidence.** `route` sends contradictory or ambiguous sources to review, because confidence measures the model's certainty, not the document's consistency.
5. **Audit by stratum.** `sample_for_audit` samples per type and field, so rare, failure-prone segments are not drowned out; it is the only way to measure error in the high-confidence band.

## Trade-offs

| Choice | Strength | Cost |
| --- | --- | --- |
| Per-field thresholds | Accurate for fields of differing difficulty | More labelled data and upkeep; a global threshold over-accepts hard fields or over-reviews easy ones |
| Higher accuracy target | Fewer errors | More items to humans; set from the cost of an error, not a round number |
| Larger stratum samples | Tighter error estimates | Reviewer time; small strata may need all items |
| Labelled set | Ties confidence to reality | Decays as document mix or model version changes; recalibrate and keep sampling |
| Self-reported confidence | Cheap | Useful only once calibrated; independent-pass agreement or validation failures add signals |
| Full vs selective review | Full is safest | Does not scale; selective depends on sound calibration |

> [!WARNING]
> **Exam traps**
>
> - **"97% overall accuracy, so automate"** → aggregates mask segment failures. Validate by document type and field before reducing review.
> - **"Trust the model's confidence score as is"** → uncalibrated. Calibrate thresholds on a labelled validation set.
> - **"Review a random sample of everything"** → wastes capacity on easy items and under-samples rare types. Use stratified sampling plus targeted review of low-confidence and ambiguous items.
> - **"Stop reviewing once confidence is high"** → high-band errors and new patterns go undetected. Keep sampling auto-accepted output.
> - **"Use one threshold for all fields"** → fields differ in difficulty. Calibrate per field.
> - **"Auto-accept when confident even if sources disagree"** → confidence does not resolve contradictions. Route them to humans.
