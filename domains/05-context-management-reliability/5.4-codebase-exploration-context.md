# 5.4 Manage context effectively in large codebase exploration

## Knowledge of

- Context degradation in extended sessions: models start giving inconsistent answers and referencing "typical patterns" rather than specific classes discovered earlier.
- The role of scratchpad files for persisting key findings across context boundaries.
- Subagent delegation for isolating verbose exploration output while the main agent coordinates high-level understanding.
- Structured state persistence for crash recovery: each agent exports state to a known location, and the coordinator loads a manifest on resume.

## Skills in

- Spawning subagents to investigate specific questions (e.g., "find all test files," "trace refund flow dependencies") while the main agent preserves high-level coordination.
- Having agents maintain scratchpad files recording key findings, referencing them for subsequent questions to counteract context degradation.
- Summarizing key findings from one exploration phase before spawning sub-agents for the next phase, injecting summaries into initial context.
- Designing crash recovery using structured agent state exports (manifests) that the coordinator loads on resume and injects into agent prompts.
- Using `/compact` to reduce context usage during extended exploration sessions when context fills with verbose discovery output.

## Code snippets

### Scratchpad file for findings that must survive context loss

```text
Instruction in the prompt or CLAUDE.md:
"Maintain SCRATCHPAD.md. After each exploration step append: files examined, key classes
 (with paths), data flow, open questions. Re-read it before answering follow-up questions
 instead of relying on memory."
```

```markdown
<!-- SCRATCHPAD.md -->
## Refund flow
- Entry: payments/refunds.py:process_refund() -> RefundPolicyChecker (policy/checker.py)
- Writes: ledger/entries.py:LedgerEntry; emits RefundIssued event (events/bus.py)
## Open questions
- Where is the partial-refund rounding done?
```

Late in a long session, a degrading model starts saying "typical patterns" instead of naming the specific classes it found. The scratchpad counters that.

### Delegate verbose exploration, keep a summary

```text
Use the Explore subagent: "Find all test files related to refunds and list how each is run."
Use a subagent: "Trace the refund flow and return the call chain with file:line references only."
```

The subagent's tool calls stay in its own context; only its final message returns.

### Summarise one phase before starting the next

```python
phase1_summary = ask("Summarise findings from the exploration so far: modules, entry points, risks.")
phase2 = ask(f"<prior_findings>\n{phase1_summary}\n</prior_findings>\n\nNow investigate the ledger writes.")
```

### Control compaction

```text
/compact                       compact on demand when verbose discovery output has filled context
```

```markdown
<!-- CLAUDE.md: tells the compactor what to preserve -->
# Summary instructions
When summarising this conversation, always preserve:
- The current task objective and acceptance criteria
- File paths that have been read or modified
- Test results and error messages
- Decisions made and the reasoning behind them
```

Project-root CLAUDE.md is re-read after compaction, so persistent rules belong there rather than in the first prompt. In the Agent SDK a `PreCompact` hook (input has `trigger: "manual" | "auto"`) can archive the full transcript before it is summarised.

### Crash recovery with a manifest

Each agent writes its state to a known location; the coordinator loads the manifest on resume and injects it into agent prompts.

```python
import json
from pathlib import Path

STATE_DIR = Path(".agent_state")


def save_state(agent: str, state: dict) -> None:
    STATE_DIR.mkdir(exist_ok=True)
    (STATE_DIR / f"{agent}.json").write_text(json.dumps(state, indent=2))
    manifest = {p.stem: {"updated": p.stat().st_mtime, "path": str(p)} for p in STATE_DIR.glob("*.json") if p.stem != "manifest"}
    (STATE_DIR / "manifest.json").write_text(json.dumps(manifest, indent=2))


def resume_prompts() -> dict[str, str]:
    manifest = json.loads((STATE_DIR / "manifest.json").read_text())
    return {
        agent: f"<prior_state>\n{Path(meta['path']).read_text()}\n</prior_state>\nContinue from this state."
        for agent, meta in manifest.items()
    }
```
