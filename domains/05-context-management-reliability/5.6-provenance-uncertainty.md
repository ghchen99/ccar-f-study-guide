# 5.6 Preserve information provenance and handle uncertainty in multi-source synthesis

> [!NOTE]
> **At a glance**
>
> - **Claim-source mappings:** structured findings keep attribution through summarisation; synthesis must preserve and merge them.
> - **Conflicts:** annotate credible disagreements with source attribution; never pick one silently.
> - **Dates:** require publication or collection dates so time differences are not read as contradictions.
> - **Report shape:** separate established, contested and uncovered findings.

## Example

### Subagent output: claim-source mappings with dates

```python
from typing import TypedDict


class Finding(TypedDict):
    claim: str
    evidence_excerpt: str          # lets a reader check the claim without refetching the source
    source_url: str | None
    document_name: str | None      # either URL or document name identifies the source; both optional for that reason
    page: int | None
    published: str                 # ISO date of publication / data collection; separates change over time from contradiction
    methodology: str | None        # e.g. "survey, n=2,000"; explains why credible sources can differ
```

The synthesis agent must preserve and merge these mappings; if attribution is dropped in summarisation, claims become unsourceable.

### Conflicting values: annotate, do not pick

```json
{
  "claim": "Share of studios using generative tools",
  "values": [
    {"value": "62%", "source": "https://a.example/report", "published": "2025-06-01", "methodology": "survey, n=800"},
    {"value": "41%", "source": "https://b.example/study",  "published": "2024-02-15", "methodology": "survey, n=2,000"}
  ],
  "conflict": true,
  "note": "Different years and sample sizes; may reflect growth, not disagreement"
}
```

Include both values in document analysis and let the coordinator reconcile before synthesis. A 2024 figure and a 2025 figure are a time difference, not a contradiction.

### Report structure that separates established from contested

```markdown
## Well-established findings
- AI image tools are widely used in concept art (4 independent sources: [1][2][3][4])

## Contested findings
- Adoption rate: 41% (Study B, 2024) vs 62% (Report A, 2025). Different dates and samples; see sources.

## Coverage gaps
- Music licensing: no source available (search timed out)
```

### Render each content type appropriately

| Content | Format |
| - | - |
| Financial figures, comparisons | Table |
| News and context | Prose |
| Technical findings | Structured list |

Do not flatten everything into one uniform bullet format.

### Synthesis instruction

```text
For every claim keep its source_url/document_name and published date. When two credible
sources give different figures, report both with attribution and the context (date,
methodology). Do not choose one. Put widely corroborated findings and disputed findings
in separate sections.
```

## How it works

> [!IMPORTANT]
> **Every claim carries its provenance through every stage, and uncertainty is shown, not silently resolved.** An agent without the authority or evidence to choose between sources surfaces the disagreement to the coordinator or reader.

1. **Bundle provenance.** `Finding` holds claim, excerpt, locator (URL or document name, page), date and methodology: where from, can I verify it, how old, how measured. Prose compression drops these.
2. **Require dates.** A 2024 figure of 41% and a 2025 figure of 62% may be growth, not disagreement; without dates synthesis flags a false conflict or picks one.
3. **Record methodology.** Sample size, population and definition explain why credible sources legitimately differ.
4. **Annotate conflicts.** Keep both values with source, date and methodology and set `conflict: true`. Averaging invents a number no source reported; picking hides the disagreement. Analysis completes rather than stopping at the first disagreement.
5. **Three-section report.** Well established, contested and coverage gaps show reliability at a glance; gaps from unavailable sources link back to [5.3](5.3-error-propagation.md).
6. **Match format to content.** Tables for financial data, prose for news, lists for technical findings (uniform bullets can destroy comparisons); restate keep-source, report-both, do-not-choose rules in the synthesis instruction.

## Trade-offs

| Choice | Strength | Cost |
| --- | --- | --- |
| Rich provenance | Citable and auditable | Tokens and schema complexity; lighter form fine for throwaway summaries |
| Surface conflict | Honest | Shifts work to the reader |
| Resolve conflict | Cleaner answer | Only with a justified, stated and recorded rule (e.g. prefer more recent); an implicit pick is never justified |
| Resolve at coordinator | Broader view; can request more evidence | A synthesis agent on fixed input cannot |
| Short excerpts | Small context | Weaker verification; include a pointer to the full source |
| Type-appropriate format | Readable, keeps structure | More effort than a uniform format |
| Corroboration counting | Strengthens "well-established" | Sources must be truly independent |

> [!WARNING]
> **Exam traps**
>
> - **"Average the two statistics" / "use the more recent one without saying so"** → invents or silently chooses a value. Annotate the conflict with attribution and let the coordinator or reader decide.
> - **"Pick the most authoritative-looking source"** → arbitrary selection hides the disagreement. Do not choose between conflicting credible sources.
> - **"Summarise findings into a short paragraph before synthesis"** → attribution is lost. Pass structured claim-source mappings.
> - **"Treat different values as contradictory"** → they may come from different dates. Require publication or collection dates.
> - **"Drop the claim when sources disagree"** → loses information. Keep both with context.
> - **"Format every section as bullets for consistency"** → distorts content types. Tables for financial data, prose for news, lists for technical findings.

## Check yourself

<details>
<summary>Two reputable reports give 41% and 62% for the same adoption statistic. What should synthesis do?</summary>

Report both with sources, dates and methodologies, mark the claim as contested, and note the difference may reflect timing or sample. Do not choose or average.
</details>

<details>
<summary>A final report contains claims that cannot be traced to a source. What went wrong upstream?</summary>

Attribution was dropped during summarisation. Subagents must output claim-source mappings that synthesis preserves and merges.
</details>

<details>
<summary>A statistic changed between 2023 and 2025 in two sources. Is this a conflict?</summary>

Not necessarily. With dates present it can be reported as change over time, which is why publication dates are required in structured output.
</details>
