# Guided exercises

Build the patterns rather than only reading about them. Each exercise begins with an objective and steps, then provides a worked solution and checklist.

> Attempt the steps first. Use the worked solution to compare decisions, not as the default starting point.

## 1 — Build an agent with escalation

[Open Exercise 1](01-multi-tool-agent-escalation/README.md)

Build a multi-tool agent that uses structured tool errors and deterministic escalation rules.

**Practice:** Domains 1, 2, and 5  
**Tools:** Messages API · Tool use

**After completing:** [Customer Support scenario](../scenarios/01-customer-support-resolution-agent/README.md)

## 2 — Configure Claude Code for a team

[Open Exercise 2](02-claude-code-team-workflow/README.md)

Configure shared instructions, path-specific rules, skills, commands, and MCP access.

**Practice:** Domains 2 and 3  
**Tools:** CLAUDE.md · Rules · Skills · `.mcp.json`

**After completing:** [Code Generation scenario](../scenarios/02-code-generation-with-claude-code/README.md)

## 3 — Build a structured extraction pipeline

[Open Exercise 3](03-structured-extraction-pipeline/README.md)

Combine schemas, validation retries, batch processing, and human-review thresholds.

**Practice:** Domains 4 and 5  
**Tools:** Messages API · Batches API · Pydantic

**After completing:** [Structured Data Extraction scenario](../scenarios/06-structured-data-extraction/README.md)

## 4 — Build a multi-agent research pipeline

[Open Exercise 4](04-multi-agent-research-pipeline/README.md)

Coordinate specialized agents with scoped context, structured errors, and provenance-preserving synthesis.

**Practice:** Domains 1, 2, and 5  
**Tools:** Claude Agent SDK

**After completing:** [Multi-Agent Research scenario](../scenarios/03-multi-agent-research-system/README.md)
